# 🏢 SitexNow Homelab

> **Building an enterprise infrastructure and cybersecurity lab from scratch while documenting every step of the learning journey.**

---

# 📖 About

This repository documents the implementation of a complete enterprise homelab focused on Infrastructure, DevOps and Cybersecurity.

The project combines formal education, industry certifications and hands-on experience to simulate real-world corporate environments.

Every configuration, challenge and lesson learned is documented throughout the journey.

---

# 🎯 Objectives

* Learn enterprise infrastructure
* Master Windows Server and Active Directory
* Develop networking skills
* Build monitoring and security platforms
* Practice Blue Team operations
* Create a professional technical portfolio
