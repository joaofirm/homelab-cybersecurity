# 🏢 SitexNow Homelab

Welcome to my enterprise homelab project.

This repository documents the complete implementation of a simulated corporate infrastructure designed to develop practical skills in System Administration, Networking, Virtualization and Cybersecurity.

## 🎯 Objectives

- Learn Windows Server administration
- Deploy and manage Active Directory
- Configure DNS, DHCP and Group Policies
- Implement pfSense as enterprise firewall
- Monitor infrastructure with Zabbix
- Centralize security events with Wazuh
- Simulate attacks and incident response
- Build a portfolio based on real-world scenarios

## 🛠️ Technologies

- VMware Workstation Pro
- Windows Server 2022
- Windows 11
- Ubuntu Server
- Active Directory
- DNS
- Group Policy
- pfSense
- Zabbix
- Wazuh
- Kali Linux
- PowerShell
- Bash
